## 3. Verified Statistical Sign Convention

Across all paired cluster bootstrap evaluations ($B = 2,000$ replicates, $K = 180$ clusters):
$$\Delta = \text{Metric}_{\text{variant}} - \text{Metric}_{\text{baseline}}$$
- For error metrics (Mastery MAE, Probability Absolute Error, Log Loss):
  - **$\Delta < 0$ (Negative Difference):** The variant achieved lower error than the baseline (**error reduction**).
  - **$\Delta > 0$ (Positive Difference):** The variant achieved higher error than the baseline (**degradation**).
- **Statistical Significance Requirement:** An intervention is claimed to be statistically significant **if and only if** the 95% bootstrap confidence interval $[CI_{\text{lower}}, CI_{\text{upper}}]$ strictly excludes zero. If the interval contains zero, the result is explicitly categorized as `not_significant_ci_crosses_zero`.
